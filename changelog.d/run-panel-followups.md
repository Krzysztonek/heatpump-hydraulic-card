- Run details: a tap on a period that holds several compressor runs selects the run at the tapped time, not the first run of the period. A run cut by the start of the timeline stays selected while the window moves, and asks the recorder once instead of on every update.
- Run values: an unavailable sample or a negative flow-rate marker ends the value before it, so a mean leaves the gap out instead of carrying the last value across it. The tank start value needs a sample at or before the start of the run. Heaters running one after the other add up, an overlap counts once, and a heater or defrost entity without recorder history in the window is left out instead of shown as off.
- Open3E: the water pressure is the heating pressure at the first circuit (`hc_pressure`), also when the card starts at circuit 2. It was mapped as brine pressure, which an air unit does not draw (#318).
